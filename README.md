# A Cavalgada Encantada de Helena

Convite digital infantil premium com tema **Vaqueira / Cavalo / Fazendinha**, criado para o portfólio da K2 Tech.

## Conceito

Uma pequena vaqueira de 6 anos vive uma aventura delicada com seu cavalo em uma fazendinha florida. O visual combina fotografia realista, tons suaves e interações infantis.

## Experiência

- abertura fullscreen com scroll bloqueado;
- porteira animada antes de entrar no convite;
- apresentação da aniversariante;
- data, horário e contagem regressiva;
- história/mensagem;
- galeria temática;
- mini-game para encontrar lacinhos perdidos;
- localização;
- confirmação de presença;
- encerramento cinematográfico.

## Tecnologias

- Next.js
- React
- TypeScript
- Framer Motion
- Lucide React

## Desenvolvimento

```bash
npm install
npm run dev
```

Build de produção:

```bash
npm run build
```
